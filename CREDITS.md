## Structural references

The implementation uses established, lightweight conventions from:

- Tailwind CSS for a utility-first styling system and explicit design tokens.
- shadcn/ui's compositional idea of keeping small UI primitives in the codebase, adapted here without its CLI or extra runtime dependencies.
- React's component composition model and Vite's minimal build setup.

No third-party design is copied. These references guide organization, reuse, accessibility, and build simplicity.
